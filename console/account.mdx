The **Account** page holds the settings of your workspace, the IronBee account your projects belong to. **Settings** opens on this page. You can also reach it with **Account settings** in the account switcher.

## Account name

The page shows the **Account Name** and **Your Role** in it. Owners and admins also see the **Owner**.

To rename the account, the owner clicks **Change Name**, enters the new name in **Change account name** and clicks **Save**. Names use letters, numbers and spaces, up to 64 characters.

---

## Account API key

Owners and admins see the **Account API Key**: one shared key for the whole account. It identifies no user, which suits CI and deployment tooling.

- The **GitHub Action** takes it as the `ironbee_api_key` input.
- The **CLI** reads it from `IRONBEE_SERVICE_API_KEY`.

Use the icons next to the key to show, hide or copy it.

<Warning>
  Never commit this key to git or share it in plain text. Store it as a secret in your CI provider, such as a GitHub repository secret named `IRONBEE_API_KEY`.
</Warning>

For your own machine, sign in with `ironbee login` instead. It creates a personal [OAuth token](/console/access-tokens) that you can revoke on its own.

---

## Rotate the API key

Rotate the key when it may have leaked, or on a regular schedule:

1. Click **Rotate** next to the key. **Rotate account API key?** asks you to confirm. Click **Rotate key**.
2. **Copy the new API key** shows the new key once. Copy it, tick **I have copied the new key to a safe place.**, and click **Done**.
3. Update the key wherever you use it.

<img className="ib-shot ib-shot-light" src="/images/console/settings/rotate-key-dialog-light.png" alt="Rotate account API key? dialog explaining that the current key stays active for 24 hours, with Cancel and Rotate key buttons" />
<img className="ib-shot ib-shot-dark" src="/images/console/settings/rotate-key-dialog-dark.png" alt="Rotate account API key? dialog explaining that the current key stays active for 24 hours, with Cancel and Rotate key buttons" />

The previous key keeps working for a 24-hour grace window, so running jobs and pipelines don't break while you update them. The page lists it as **Previous Key (Grace Window)**, with its expiry. Click **Deactivate now** to end the grace window early.

If you rotate again while a previous key is still in its grace window, **Replace previous grace key?** asks you to confirm. Click **Replace and rotate**. The older grace key stops working at once.
