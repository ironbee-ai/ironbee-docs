Open **Settings** from the gear at the bottom of the sidebar, or from your user menu. The settings menu has two parts:

| Section | Page | Who sees it |
|---------|------|-------------|
| | **Getting started** | Owners and admins |
| **Personal** | [Profile](/console/profile) | Everyone |
| | [OAuth Tokens](/console/access-tokens) | Everyone |
| | **Visual** | Everyone |
| **Workspace** | [Account](/console/account) | Everyone. Some parts are for owners and admins only |
| | [Team](/console/team) | Owners and admins |
| | **Archived projects** | Owners and admins. See [Project settings](/console/project-settings#unarchive-a-project) |
| | [Pricing](/console/pricing) | Owners and billing admins |

**Settings** opens on **Account**. **Getting started** reopens the onboarding steps, to connect another provider or set up the CLI.

---

## Visual

The **Visual** page controls how the console looks and shows your data. Changes apply immediately and are saved in your browser, so each browser keeps its own choices.

<img className="ib-shot ib-shot-dark" src="/images/console/settings/visual-settings-dark.png" alt="Settings menu with the Personal and Workspace groups, and the Visual page with Sidebar Position, Color Theme, Default View and Time Format" />

### Appearance

| Setting | Options |
|---------|---------|
| **Sidebar Position** | **Left** or **Right** |
| **Color Theme** | **Dark** (the default) or **Light** |

### Data display

| Setting | Options |
|---------|---------|
| **Default View** | **Card** or **List**, for the [Projects](/console/projects) page |
| **Time Format** | **12-hour** (`4:30 PM`, the default) or **24-hour** (`16:30`), for every clock in the console, in lists and filters alike |
