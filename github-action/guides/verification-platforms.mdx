title: Local-mode platforms
description: Choose the IronBee DevTools platforms the agent verifies through when the verification runs on your runner.
---

When the verification runs on your GitHub runner (local mode), the agent verifies through IronBee DevTools, the same platforms the [CLI uses](/cli/concepts/how-it-works). You choose which platforms it gets.

<Note>
  These inputs apply to local mode only. On IronBee, the run verifies your web app in a browser, and the action logs a warning if you set them. See [Platform and local verification](/github-action/concepts/verification-modes).
</Note>

---

## The platforms

| Platform | Input | Default | Verifies through |
|----------|-------|---------|------------------|
| Browser | `ironbee_browser_devtools` | `true` | A real Chromium browser: navigation, DOM, console, accessibility, screenshots, recording |
| Backend | `ironbee_backend_devtools` | `false` | Real protocol calls: HTTP, gRPC, GraphQL, WebSocket, databases, logs |
| Node.js | `ironbee_node_devtools` | `false` | The Node.js runtime: tracepoints, exceptions, variables, HTTP capture |
| Python | `ironbee_python_devtools` | `false` | The Python runtime through debugpy: tracepoints, exceptions, logs, thread dumps |
| Terminal | `ironbee_terminal_devtools` | `false` | CLI, REPL and TUI programs, driven through a pseudo-terminal |

Only the browser runs by default. Turn on the others when those layers are part of the change:

```yaml
- uses: ironbee-ai/ironbee-action@v1.1.0
  with:
    ironbee_api_key: ${{ secrets.IRONBEE_API_KEY }}
    anthropic_api_key: ${{ secrets.ANTHROPIC_API_KEY }}
    verification_mode: local
    ironbee_browser_devtools: 'true'
    ironbee_backend_devtools: 'true'
```

<Warning>
  The terminal platform gives the agent a shell on the runner. Turn it on only when a command-line program is what you are verifying.
</Warning>

All enabled platforms are served by one `ironbee-devtools` MCP server. Its log is written to `.ironbee/artifacts/ironbee-devtools-mcp.log` and ships with the [evidence artifact](/github-action/advanced/evidence).

---

## Browser on CI runners

GitHub-hosted Linux runners reject user-namespace sandboxing, which would otherwise stop Chromium on its first navigation. The action launches Chromium with `--no-sandbox` for you. No configuration is needed.

---

## Tuning a platform

To pass extra environment variables to the DevTools server, or to change other CLI settings, use `ironbee_extra_config`. See [Custom configuration](/github-action/advanced/custom-configuration).
